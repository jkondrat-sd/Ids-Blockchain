# Dataset

This project uses **CSE-CIC-IDS2018** (Canadian Institute for Cybersecurity). The raw files are about 16 GB and are not stored in this repository.

Download the ten `*TrafficForML_CICFlowMeter.csv` files from the [official dataset page](https://www.unb.ca/cic/datasets/ids-2018.html) and place them in this folder:

```
data/
├── Friday-02-03-2018_TrafficForML_CICFlowMeter.csv
├── Friday-16-02-2018_TrafficForML_CICFlowMeter.csv
└── ...
```

CSV files are ignored by git.
